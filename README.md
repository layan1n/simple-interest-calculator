# Simple Interest Calculator

A Bash script that calculates simple interest using the principal, annual interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Usage
Run `bash simple-interest.sh` and enter the principal amount, annual interest rate (percentage), and time period in years.

## Example
Principal: 1000
Rate: 5
Time: 2
Simple Interest: 100.00
