# Contributing

All contributions, bug reports, documentation improvements, enhancements, and ideas are welcome.

## How to contribute
1. Fork the repository.
2. Create a feature branch.
3. Make and test your changes.
4. Commit with a clear message.
5. Open a pull request explaining the change.

## Reporting bugs
Open an issue describing the problem, steps to reproduce, expected behavior, and actual behavior.

## Suggestions
Share improvement ideas through GitHub issues.

Please follow the CODE_OF_CONDUCT.md and keep contributions respectful and focused.
